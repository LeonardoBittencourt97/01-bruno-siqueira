# Escritório de Advocacia Bruno Siqueira

Landing page do escritório de advocacia Bruno Siqueira em Curitiba, PR.

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O build gera a pasta `dist/` pronta para deploy.

## Deploy

Conecte o repositório na Vercel:

- Framework: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Sem env vars necessárias

## Stack

- Vite
- React 19
- TypeScript
- Tailwind CSS v3
- Phosphor Icons
